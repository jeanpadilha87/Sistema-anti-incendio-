1. OBJETIVO DO PROJETO

Desenvolver um sistema embarcado utilizando Arduino Uno para monitorar temperatura, presença de gases e luminosidade, identificando possíveis situações de incêndio e emitindo um alerta sonoro.


2. COMPONENTES UTILIZADOS

- 01 Arduino Uno
- 01 Sensor de gás MQ-2
- 01 Sensor de temperatura TMP36
- 01 Sensor de luminosidade LDR
- 01 Buzzer
- 01 Display LCD 16x2 I2C
- 01 Protoboard
- Resistores e jumpers


3. CUSTO ESTIMADO

Arduino Uno R$ 49,90

Sensor LDR R$  0,50
Buzzer R$  2,18

TOTAL ESTIMADO:                     R$ 142,20

4. ESQUEMA DE MONTAGEM

A montagem do circuito foi desenvolvida utilizando
o simulador Tinkercad Circuits.

O sistema utiliza o Arduino Uno conectado aos três
sensores, ao buzzer e ao display LCD.

5. CÓDIGO-FONTE

O código-fonte foi desenvolvido em linguagem C++,
utilizando a plataforma Arduino.
